# Course project materials

These files come from the original Temple University CIS 3296 team project
(spring 2026). They describe that earlier version of WatchyoJet and are kept
for the record of the team's work:

- `presentation.html`: the final course presentation.
- `uml.html`: UML diagrams of the course-era class design.

The current design is described in the main [README](../../README.md) and the
[system documentation](../WATCHYOJET_DOCS.md). Class names, thresholds and the
data flow have changed since these were made.
